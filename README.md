# Richline Website V2 — Standalone Foundation

Independent static website codebase. It does not depend on or modify the Richline One enterprise system.

## Preview locally

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Files
- `index.html` — production homepage foundation
- `styles.css` — responsive design system and layout
- `script.js` — sticky header, mobile menu and trust-counter animation
- Homepage trust section — verified milestones and Richline trust commitments
- `public/products/` — supplied Richline product renders

## Hosting
This static build can be hosted on Azure Static Web Apps, Netlify, Vercel, Cloudflare Pages, Hostinger, or any standard web hosting.
